# pianolearning

A theory-first, MIDI-native piano learning path: from zero to fluent in the _system_ of the keyboard — scales, chords, inversions, functional harmony — so songs become something you can reason about.

**Start here:**

- [PLAN.md](PLAN.md) — the project plan: landscape research (open source + commercial), the 8-stage learning path, product design, tech stack, and roadmap.
- [IMPLEMENTATION.md](IMPLEMENTATION.md) — the build specification: detailed docs (architecture, data model, MIDI/audio, exercise engine, UI/UX, curriculum content, progress/scheduling, phased build order) written so an implementing agent can build the finished product from them.
