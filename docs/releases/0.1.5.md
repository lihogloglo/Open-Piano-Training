# Keysense 0.1.5

## French support

- Use French throughout the interface, lessons, exercise feedback, and accessibility labels.
- Choose English, French, or the system language on the welcome screen or in Settings.
- Language changes preserve saved progress.
- Translation catalogs and contributor instructions make additional languages easier to add.

## Shorter practice when you know the material

- Skip lesson practice and ordinary assessments immediately, without enabling tourist mode.
- Select 100% tempo directly. Passing it completes the tempo ladder without the slower repetitions.
- Skip warmup and review exercises without changing skill scores.
- Skipped assessments remain marked for later review. Checkpoint assessments still require a pass to unlock the next stage.

## Windows and Linux downloads

- Windows x64: installer and portable executable.
- Linux x64: AppImage and Debian package.
- Piano samples are bundled for offline practice.

Linux packages target compatible desktop Linux systems. AppImage users need the system libraries and sandbox support required by Electron.
