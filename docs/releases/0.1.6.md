# Keysense 0.1.6

**Early release: this project is not thoroughly tested and needs more love.**
Expect bugs and rough edges. Hardware testing, teacher feedback, and contributions are welcome.

- Project code and original content now use the MIT license.
- Windows and Linux packages no longer include piano recordings.
- Enable sound to download piano samples directly from their existing provider. First use requires internet access.
- Downloaded samples are cached on your device. Clearing app data removes the cache.
- Full third-party licenses and font notices are available from Settings.
- The public Git history uses a noreply email and omits private session links.
- Four transitive toolchain dependencies were updated to address reported vulnerabilities.

Practice progress stays on your device. The sound provider receives normal download requests, including your IP address.
Windows executables are not code-signed.
